# (Messenger for The Odin Project)[https://www.theodinproject.com/lessons/nodejs-messaging-app]

## Objective

Originally the app was meant to be less of a real time communication app and more of a messaging board. However, having tried to implement it on my own I do feel like I missed the mark on my own.

That being said, the app does have the required authorization.
If two users are to log on at the same time they would be able to send messages to each other in a singular room.
